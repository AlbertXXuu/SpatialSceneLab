## 范围与已观察问题

下一阶段交付本地 Blender 工作流：已准备的 RGB-D、标定/位姿与对象盒先验 →
重建观测表面 → 对象分区与未决边界查看 → 用户修正 → 平移与旋转 →
保存、重开和导出可继续编辑的场景。

基线把 275 个 Sofa0 候选边界三角面留在环境层。这是**候选区域，不是已经确认的
275 个归属错误**。当前公开 fixture 只有两个简单盒子；实景仅一处，缺少独立
实例真值。新评测直接检查对象选择质量、编辑后果与任务完成。普通 RGB 的相机
恢复、未观察表面恢复和物理仿真分别属于其他能力。

## 研究问题与假设

固定同一重建网格，弱对象盒、表面邻接和多视角观测证据，能否提高目标已观测
表面的选择质量，同时控制非目标表面误移动？显式不确定性与有限人工修正，
能否减少整理工作？

证据引导分区目前是研究假设。先实现下面的直接基线；图优化或新依赖须对应
这些基线的已记录失败。保留未决归属。自动输出与辅助输出分别评测，辅助结果
不能充当自动分割性能。

## 场景矩阵与数据获取

主实验计划包含 **24 个独立原创场景组**：6 个开发组、18 个留出测试组。
这是建设目标，数量本身不保证统计充分。先建设六个多样开发组，用场景间方差
规划统计精度；确需增加测试组，应在查看留出方法对比结果前决定。

| 因素 | 构造情况 | 记录的证据 |
| --- | --- | --- |
| 几何 | 曲面/凹面、椅腿、层板、小物体 | 实例几何、面积、最小特征宽度 |
| 接触与邻近 | 接地/靠墙、相邻家具、对象盒重叠 | 接触关系、米制间距、盒重叠 |
| 外观 | 相近颜色、同一对象内部颜色突变 | 材质归属和受控外观变化 |
| 可见性 | 局部遮挡、窄覆盖、稀疏轨迹 | 帧数、目标可见面积、未观察比例 |
| 传感器与先验 | 深度噪声/缺失、位姿误差、盒尺寸/朝向错误 | 米制噪声、角度、缺失比例 |
| 组合压力 | 接触+同色+遮挡；薄结构+深度噪声 | 各因素水平及组合 |
| 连续任务 | 平移、旋转、两个对象连续编辑、修正后撤销/重开 | 任务定义、枢轴、变换、预期状态 |

单因素实验定位原因，组合实验检查相互影响。使用多种家具几何与房间布局，
不能用两盒子的换色副本充当复杂场景。扰动范围来自已记录输入行为、开发集
测量或明确压力假设，并在测试前固定。

外部验证的数据获取目标为 **6 个独立真实房间**，其中至少 4 个具备可用实例
参考标签。入组前检查访问条款、格式和参考资格；当前尚未取得这些数据。
既有无许可证 tea_room 保留为本地定性压力案例，不能满足公开数据或独立标签
门槛。真实输入缺失时，实景泛化验收保持未完成；原创实验可按自己的范围报告。

原创输入与产物明确再分发条款，外部数据及派生产物沿用各自条款。ScanNet 可
作为带标签参考源之一，但官方要求数据访问协议，不能视为可立即打包的依赖。
本协议不代表已经申请访问、签署条款或获得再分发权。

## 独立性与参考构建

按完整房间/资产/轨迹组划分。相同网格、布局、重复扫描、帧、噪声种子及扰动
版本留在同一集合；变体不增加独立场景数。开发标签用于选参数，测试标签仅供
评估。根据测试结果调参的新版本，需要新的留出比较才能主张泛化。

所有方法共享 RGB-D、位姿、对象盒、由输入定义的候选域与 TSDF 网格。物理几何
和射线标签保存为仅供评估的参考包。对网格进行均匀面积采样，用已记录的距离/
可见性规则关联独立带标签表面；匹配容差在开发集冻结，并公布容差敏感性。
无法可靠对应的样本保留不可评分状态，报告面积与保守上下界。不能用被测盒
归属生成它自己的真值。

实景标签说明来源、不确定区域和复核流程；没有独立复核时，标签可靠性标为
未验证。分别报告重建观测表面的正确性、参考可见表面覆盖、完整对象覆盖。
任何得分都不代表已经恢复未观察背面。

## 对照方法

| 编号 | 基线 | 作用 |
| --- | --- | --- |
| B0 | 当前三顶点归属一致规则 | 保留已发布参考 |
| B1 | 三角面质心的唯一盒归属 | 检查简单规则是否足够 |
| B2 | 面内面积采样或盒边界裁切 | 区分离散化与推断错误 |
| B3 | 有种子的几何区域生长 | 对照无多视角证据的邻接/法向连续性 |
| B4 | 多线索交互图分区 | 在相同修正预算下对照更强经典方法 |
| Oracle | 同一网格的独立参考归属 | 估计分区上限，不作为可用算法 |

固定预处理、候选域、种子预算和允许修正操作。B4 公布具体能量与实现；网格
适配不等于复现 RGB-D 图像论文。主张研究贡献时核对最相关的已发表 3D/交互
方法；输入与资源契约可行就运行，否则解释缺失比较、限定结论范围，不主张
SOTA。资源不可行不能证明自己更强。

## 指标与统计单位

主要按表面面积加权，不按点数或三角面数加权。分区 IoU/precision/recall 和编辑
面积比例统一使用**同一固定重建网格中，由独立参考标注且可评分的面积**。目标
分母包含候选域外的可评分目标面积；候选域外目标仍算遗漏。参考可见重建覆盖率
另在独立参考表面计算，不能把物理参考面积混入分区分母。不可评分面积与保守
上下界单列；风险/覆盖率的候选域分母与全网格指标域分别定义。

| 指标 | 定义与报告方式 |
| --- | --- |
| 目标 IoU、precision、recall | 对独立目标标签按面积计；未决目标面积仍算遗漏 |
| 漏编辑 | 未被施加规定变换的可评分目标网格面积 / 全网格可评分目标面积 |
| 误编辑 | 被移动的可评分非目标网格面积 / 全网格可评分目标面积；另列墙、地板、其他对象 |
| 风险与覆盖率 | 接受归属中错误面积 / 接受归属面积，同时列接受面积 / 固定可评分候选域面积；报告整条曲线与参考标签可用比例 |
| 编辑几何保持 | 均匀面积采样与理想刚体变换的米制 p50/p95/max 距离、其他几何漂移 |
| 辅助任务成本 | 相同预算下修正笔画/操作数、耗时、撤销/重开成功与最终质量 |
| 耗时与资源 | 进程树峰值 RAM、相关 VRAM、墙钟、各负载交互响应 |
| 导出保持 | 原生重开后的世界几何、拓扑、UUID、单位、归属与颜色/材质 |

预先声明的自动方法主指标为场景宏平均目标 IoU，误编辑面积为保护指标。
误编辑的非劣容许界限来自开发任务的可接受误差，并在测试前冻结。即使标量
有利，也报告风险/覆盖曲线和分因素结果。主张新方法优于基线，需要相对开发集
选定最强直接基线的配对场景级 95% 区间下界为正，并通过预先定义的误编辑保护
条件。这是本项目的结论门槛，不是通用论文录用规则。

公布逐场景差值，使用配对场景级 bootstrap 区间。同一场景多个噪声种子属于
组内重复测量；表面样本、三角面和帧不算独立实验主体。崩溃、OOM、空输出与
超时计入任务尝试分母，明确报告缺失得分与任务失败，不悄悄剔除后算均值。
精度不足或区间不能支持改善时，报告不确定/负结果。

## 消融与反例

逐项关闭观测可见性/来源、邻接、法向/颜色、不确定性、边界裁切，保持相同
调参机会。绘制质量—修正成本曲线，分别列自动和辅助结果。模拟修正使用固定
可检查的种子/操作策略；作者计时操作标为作者测试，不能当作用户研究。

预先纳入同色接触、对象与墙共面、几乎不可见目标、错误/缺失盒、遮挡薄结构、
零有效深度、无效位姿与输出写入失败。报告最好、典型和最差情况。未决状态
保留在保存与导出中。碰撞/开放边界提示仅描述观测表面，不证明封闭实体占用。
