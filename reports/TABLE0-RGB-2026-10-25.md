# Table0: RGB cross-check of frozen geometric candidates

Measured 2026-10-25 (Asia/Shanghai) · [中文](TABLE0-RGB-2026-10-25.zh-CN.md)

**Result: INCONCLUSIVE. The present image evidence does not justify adopting the
balanced candidate.** The experiment produced 385 descriptor-selected matches
across 15 predetermined pairs. Only two pairs meet the predeclared minimum of
30 matches and six occupied cells in each 4×3 image grid. Some pair scores improve
and others worsen; weak texture, repeated structures and correspondence ambiguity
limit interpretation. All pairs and their original score denominators are retained.

## Question and falsifiable hypothesis

The October 15 candidate improves the same 3,558 depth scoring observations from
15.393 to 8.799 mm mean residual, but support 75.295% remains below 80% and neighbour
evidence is incomplete. Its geometry gate is still FAIL. Earlier color-term
odometry used depth for projection and visibility despite optimizing intensity.

If the frozen depth-driven rigid candidate represents a shared camera improvement,
RGB correspondences not constructed from depth or either camera hypothesis should
provide compatible epipolar evidence. We fit no camera to these correspondences.
The candidate metadata explicitly says `is_camera_pose_estimate: false`; this
experiment tests that possible interpretation instead of assuming it is true.

The original `cameraPoseARFrame` may already use visual tracking. RGB was absent
from the Table0 depth objective but is not independent physical truth; capture,
calibration and possibly original pose estimation are shared.

## Environment and method

Windows CPU; Python 3.12.14, NumPy 2.3.5, Pillow 12.3.0, optional OpenCV wheel
4.13.0.92/API 4.13.0, one thread, OpenCL disabled. No GPU, model, service or paid
allocation. Preparation downloaded the free optional wheel separately from the
network-guarded experiment. Core project dependencies are unchanged.

Input is pinned `LiteReality/example-scans` commit
`3f2ca5d618fe86b264716200baea19ae0aea0d49`; all 253 source files are fingerprinted.
Unrotated 1920×1440 JPEGs use original per-frame K. We compare original cameras,
the old normal-translation candidate and the balanced candidate from the frozen
October 15 replay. Depth values, confidence and camera scores never construct or
filter matches; depth files are only checksum-verified for source identity.

Pairs were fixed before matching: 4/12 to 46–49; adjacent 45→46→47→48→49→50;
unchanged 44→45 and 50→51. Full-resolution SIFT (maximum 4,000 features), RootSIFT,
mutual bidirectional nearest-neighbour ratio 0.75, then one lowest-distance match
per pair of 8-pixel cells. No post-result parameter search or favourable-pair selection.

Every hypothesis scores the same matches using square-root Sampson distance in
original-image pixels. Report median, P95 and fraction ≤2 px. Count/grid thresholds
measure numerical coverage, not correspondence correctness. A separate fixed-seed
3 px homography RANSAC only reports compatibility; its inliers do not filter the
scores. Compatibility can reflect a plane or rotation/low parallax, while low
compatibility does not prove a reliable nonplanar match set.

independent experimental units, and no significance claim is made.

## Controls and reproducibility

A separate review agent inspected all 15 fixed-sample montages without reading
camera scores. Clear examples connect black-chair features to a whiteboard/table
edge or a package to plant leaves. Plausible samples mostly cover chairs, packages,
boards and cabinet boundaries; almost no tabletop-interior texture is confirmed.
At most eight displayed matches per pair, at 40% image scale, are qualitative
review rather than manual truth. They neither estimate a population mismatch rate
nor remove samples or define a newly selected scoring subset.

Both unchanged pairs have exactly identical scores. A fixed +2° local-Y source
rotation worsens 13/15 real-pair medians. It demonstrates sensitivity, not known
physical error: the original pose can itself be imperfect. Scaling relative
translation length by 3.7 changes scores by at most 8.41e-13 px, confirming that
absolute scale is unobservable. Separate noncoplanar analytic points test correct
pose, wrong direction/rotation, differing K, epipoles and zero baseline.

The first run aborted on the scale control: captured homogeneous rows include
float32 values such as 0.99999994, and full 4×4 inversion produced about 7.43e-6 px
of spurious scale variation. The diagnostic now uses validated rotation/centre
blocks. Original matrices, matching parameters, frame pairs and thresholds stay
unchanged; this fixes numerical interpretation in the new checker, not the capture.

Two final complete runs reproduce identical matches and result JSON. All original
inputs and candidates are preserved; the experiment takes about six seconds.
The full local suite runs 339 tests: 335 pass and four preexisting optional SciPy
cases skip. All 18 new numeric/input-contract tests pass.
Python socket/DNS guard probes pass with zero experiment events; this is not OS
isolation of native libraries. Dependency preparation and the aborted attempt are
retained separately in local evidence.

## Interpretation and next evidence

The useful result is an executable image-geometry cross-check and a measured
coverage limitation: this fixed feature configuration cannot certify the shared
camera correction. It does not prove RGB is useless or the candidate necessarily
physically wrong. It also does not justify adoption merely because a depth plane
became flatter.

The next bounded step is to establish a small set of image-content-verified rigid
feature tracks across several views, reviewed without candidate scores. Retain
ambiguous texture, occlusion and tabletop-boundary cases explicitly. First check
whether existing images support sufficient tracks; if not, design a small new
capture with texture markers, measured dimensions and timing records. A stronger
matcher can be a separately declared experiment, not repeated tuning until this
candidate wins. Physical accuracy ultimately still needs independent reference.

The original geometry gate, cameras, observations, editable scene and MAINLINE
status remain unchanged.
